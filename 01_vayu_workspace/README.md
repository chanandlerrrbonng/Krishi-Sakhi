## 🚀 Get Started

Follow these steps to launch your workspace and get going:

1. **Create a Vayu AI Studio workspace**  
   Open Vayu AI Studio and create a new workspace for your team.

2. **Clone the Repository**  
   Download this `ask-it` repository into your workspace, either by cloning it via Git or uploading manually.

3. **Install Dependencies**  
   Open a terminal inside the workspace and run:
   ```bash
   # Set up a Python 3.12 virtual environment
   pip install virtualenv

   virtualenv venv
   source venv/bin/activate

   cd ask-it
   pip install -r requirements.txt
   ```

4. **Where to Work?**  
   Use this workspace when working on:
   - [00_dataset/ — Vayu Object Storage](../00_dataset/)
   - [04_starter_kit/qna.ipynb — Vayu RAG ingest](../04_starter_kit/qna.ipynb)
   - [05_build_app/ — Vayu chat & deploy](../05_build_app/)
